# Weekly reports

Production generates `YYYY-Www.md` here from the previous `Asia/Shanghai` natural week.
These reports can contain internal business conclusions, so normal Git staging ignores them.
The weekly publisher force-adds only the selected report and refuses to publish unless the
configured GitHub repository is authenticated and private.

The fixed report contract includes key conclusions, source coverage, owner/action items,
risks, experiments, follow-ups, Git changes, Dashboard links, and the two-model quality,
latency, token, cost, and retry comparison.
